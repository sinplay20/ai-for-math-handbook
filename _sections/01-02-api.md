API 允许程序向模型发送请求并接收结果。网页适合人与模型直接交流；API 更适合批量处理、固定格式输出和自动化工作流。

#### 最小准备

1. 在模型服务商平台创建 API Key。
2. 把 Key 存入环境变量，不写入代码和 Git 仓库。
3. 安装对应 SDK，选择当前可用的模型。
4. 发送一次简单请求并打印返回结果。

#### Python 最小示例

```python
from openai import OpenAI

client = OpenAI()  # 自动读取 OPENAI_API_KEY

response = client.responses.create(
    model="YOUR_MODEL_NAME",
    input="请用三句话解释弱解与经典解的区别。"
)

print(response.output_text)
```

先运行 `pip install openai`，再把示例中的模型名替换为账户当前可用的模型。参见 [OpenAI API Quickstart](https://developers.openai.com/api/docs/quickstart)。

#### 需要建立的四个意识

- **安全**：不公开 Key，不把它提交到 Git。
- **成本**：请求通常按输入和输出用量计费。
- **稳定**：保存错误信息，为请求设置重试与限制。
- **核验**：API 输出同样可能出现事实与数学错误。
