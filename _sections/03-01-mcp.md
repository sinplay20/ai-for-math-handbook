MCP（Model Context Protocol）是连接 AI 应用与外部工具、数据和服务的标准协议，可以把它理解为 AI 应用与外部系统之间的通用接口。

- **Tools**：可以执行的操作，例如计算、查询或写入文件。
- **Resources**：可以读取的数据，例如论文、笔记和数据库记录。
- **Prompts**：可以重复使用的交互模板。

AI 应用作为 MCP Host，通过 Client 与一个或多个 MCP Server 建立连接。MCP 规定组件如何交换信息，但不规定模型必须如何使用这些信息。参见 [MCP 官方架构说明](https://modelcontextprotocol.io/docs/learn/architecture)。

#### MCP 服务推荐

#### 让 ChatGPT Desktop 帮你安装

打开 ChatGPT Desktop，在对话框中输入下面这句话，并把括号中的内容替换为上表对应的仓库地址：

```text
我是电脑小白，帮我配置mcp服务（仓库地址），需要我操作什么停下来跟我说
```

例如，安装 Zotero MCP 时，把“仓库地址”替换为 `https://github.com/54yyyu/zotero-mcp`。ChatGPT 遇到需要你点击设置、授权或重启应用的步骤时，应停下来等待你完成，再继续下一步。

<div class="warning">
  <b>安全提醒</b>
  <p>不要把 API Key、访问令牌或密码直接发送到对话中。需要密钥时，让 ChatGPT 告诉你应在哪个本地设置页面填写；安装前也应确认 MCP 服务能够读取和修改哪些数据。</p>
</div>
