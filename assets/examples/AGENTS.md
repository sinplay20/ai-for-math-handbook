# AGENTS.md

## 项目目标
协助开展数学文献阅读、证明检查、LaTeX 写作与研究资料整理。
原始文献和经人工确认的项目文稿是依据；AI 输出不是已核查的数学事实。

## 语言与格式
- 讨论、解释和修改记录默认使用中文 Markdown。
- 正式论文文字默认使用英文 LaTeX。
- Markdown 行内公式使用 $...$，独立公式使用 $$...$$。

## 数学与引用
- 不编造定理、证明、文献或页码。
- 区分原文结论、自己的推导和待核查的猜想。
- 检查假设、量词、常数依赖、定义域和边界情形。
- 引用标明来源及可核对的位置；无法核实时明确说明。

## 操作边界
- 先确认任务范围、输入材料和允许修改的文件。
- 未获授权，不写入正式手稿或知识库，不删除文件，不提交、推送或公开发布。
- 安装软件、授权、输入密钥或修改配置前，说明用途、影响和风险，等待确认。
- 密钥只在适当的本地配置或授权界面中输入，不写入此文件、聊天或版本仓库。

## 工作方式与交付
- 按小批次推进；重要歧义先询问，不把探索性建议当作已确认决定。
- 修改后运行适用的检查；没有实际运行的编译或测试，明确标注为未验证。
- 最后列出修改文件、检查结果、尚存问题和需要人工确认的事项。
- 数学判断、研究方向与最终发布决定由人负责。
